# Документация проекта ЭЗР

Добро пожаловать в документацию!  
Этот файл — **главная карта**, которая поможет тебе быстро ориентироваться во всех документах проекта.

---

## Быстрый старт (для новичков)

1. Прочитай этот файл (ты уже здесь).
2. Ознакомься с **[структурой проекта](Working%20Documentation/Project%20Folder%20Structure.md)** — пойми, где лежат скрипты, сцены и префабы.
3. Прочитай **[Code Style](Working%20Documentation/_Code%20Style.md)** — чтобы твой код был в едином стиле с проектом.
4. Установи проект (см. **[Setup Guide](Working%20Documentation/Guides/Setup.md)**).
5. Начинай работать! Если что-то непонятно — сначала загляни в **[Q&A](Working%20Documentation/Q%26A.md)**.

---

## Структура документации

```text
_templates/                     # -- Шаблоны для всех типов документов
├── JSON templates/             # Шаблоны JSON (для карт, конфигов)
│   ├── Changes Request.json    # Как предложить изменение
│   ├── Code Review Answer.json # Шаблон ответа на ревью
│   ├── Code Review Request.json# Как запросить ревью
│   ├── Meeting Draft.json      # Шаблон для встреч
│   └── Push Logs.json          # Шаблон для логов изменений
│
├── Logs/                       # -- Журналы и отчеты
│   ├── Meeting Notes/          # Конспекты встреч (дата + тема)
│   ├── Test Logs/              # Отчеты о тестировании (билды, баги)
│   └── Update Logs/            # Ежедневные/еженедельные апдейты
│
├── Working Documentation/      # -- Основная рабочая документация
│   ├── Guides/                 # Инструкции
│   │   ├── Analytics.md        # Как работают аналитические события
│   │   ├── Asset Conventions.md# Правила именования файлов
│   │   ├── Debug.md            # Частые ошибки и их решение
│   │   ├── Localization.md     # Как работает локализация (если есть)
│   │   ├── Q&A.md              # Ответы на частые вопросы
│   │   ├── Setup.md            # Развертывание проекта (Unity, пакеты)
│   │   └── Testing.md          # Как тестировать (ручное/автоматическое)
│   │
│   ├── Mechanics/              # Описание игровых механик
│   │   └── (файлы по механикам: ноты, судейство, комбо, прогрессия)
│   │
│   ├── Methods Explanations/   # -- Объяснения сложных методов
│   │   └── (файлы с пояснениями алгоритмов)
│   │
│   ├── Project Folder Structure.md  -- # Структура папок в Unity
│   ├── _Code Style.md          # Правила написания кода (C#)
│   ├── _Dev Update Logs.md     # Ежедневные заметки разработчиков
│   ├── _ReadMe.md              # Этот файл (дубликат для навигации)
│   └── _Team.md                # Команда: роли, контакты, ответственность
│
└── (корневые файлы)            # -- Глобальные настройки проекта
    ├── .editorconfig           # Настройки форматирования кода
    ├── .gitignore              # Игнорируемые файлы в Git
    └── README.md               # Этот файл (главная навигация)
```
