## Шаг 1: Клонирование репозитория

>  **Важно:** Репозиторий с игрой **закрыт**. Доступ предоставляется по запросу (см. `_Team.md`).

1. Запроси доступ к репозиторию у Техлида.
2. Склонируй проект через терминал или GitHub Desktop:

```bash
   git clone git (Укажу позже)
```
## Шаг 2: Открытие проекта в Unity

1. Запусти **Unity Hub**.
    
2. Нажми **"Open"** → выбери папку с проектом (`EZR`).
    
3. Unity автоматически подтянет все зависимости и скомпилирует проект.  
    _(Первый открытие может занять 5–10 минут)._
## Шаг 3: Установка необходимых пакетов

Некоторые пакеты уже включены в `manifest.json`.  
Если чего-то не хватает — установи вручную через **Package Manager**:

1. В Unity открой `Window → Package Manager`.
    
2. Выбери **"Packages: My Registries"** или **"Unity Registry"**.
    
3. Установи следующие пакеты:

| Пакет                          | Версия             | Зачем нужен                    |
| ------------------------------ | ------------------ | ------------------------------ |
| `Newtonsoft.Json`              | `3.2.1` (или выше) | Для парсинга JSON-карт уровней |
| `TextMeshPro`                  | последняя          | Для текста в UI                |

Если какой-то пакет не устанавливается — проверь `Architecture/DEPENDENCIES.md`.
