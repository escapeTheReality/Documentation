_Файл отвечает только за переключение и загрузку сцен_
## Объявление переменных
\[SerializeField] private Text _loadingPercentage -- отвечает за текст(цифру) процентов на экране загрузки.
\[SerializeField] private Image _progressBar -- отвечает за заполнение прогресс бара.
private static SceneSwaper instance -- статичная переменная синглтон.
private static bool shouldPlayIn = true -- флаг необходимости проигрывания стратового засветления экрана
private Animator _componentAnimator -- компонент аниматора.
private AsyncOperation loadingSceneOperation -- вытаскиваю наверх возвращаемое значение асинк загрузкой юнити

---
## public static void SwapSceneByName()
Статичность необходима для возможности вызова этого метода только указанием его класса и обращением к нему
Запускает триггер аниматора на затемнение экрана, после чего начинает грузить асинхронно новую сцену юнити. Сразу же запрещаем движку переключаться на загруженную сцену после загрузки в оперативную память

---
## public void Start()
Получаем необходимые компоненты в переменные при старте приложения, для новых сцен проверяем необходимо ли воспроизвести анимацию засветления экрана по нашему флагу shoudPlayIn

---
## public void Update()
Получаем из переменной возвращаемой методом ассинхронной загрузки юнити текущий прогресс загрузки после чего собираем из него процент и заполняем прогресс бар на необходимое колличество.

---
## public void OnAnimationOver()
Выполняем только если идет загрузка тобишь переменная loadingSceneOperation не равна null, тогда поднимаем флаг что необходимо проиграть стартовое засветление для следующей сцены и разрешаем юнити переключиться на загруженную сцену если она будет или уже была загружена.
