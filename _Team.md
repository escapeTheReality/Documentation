## Карта ответственности (RACI)

*Кто за что отвечает и кого уведомлять при изменениях:*

| Задача / Зона | Ответственный (R) | Консультант (C) | Исполнитель (I) | Кто решает споры (A) |
| :--- | :--- | :--- | :--- | :--- |
| **Архитектура кода** | Техлид | Разработчики | Техлид | Техлид |
| **Механики игры** | Гейм-дизайнер | Техлид | Разработчики | Техлид + ГД |
| **UI / Интерфейсы** | UI/UX-дизайнер | Гейм-дизайнер | UI/UX-дизайнер, Разработчики | Техлид + UI/UX |
| **Контент (карты, спрайты)** | Художник | Гейм-дизайнер | Художник | Гейм-дизайнер |
| **Звук и музыка** | Саунд-дизайнер | Техлид | Саунд-дизайнер | Саунд-дизайнер |
| **Качество (QA)** | QA-инженер | Техлид | QA-инженер | Техлид |
| **Дедлайны и процессы** | PM | Вся команда | PM | PM |

> **Расшифровка RACI:**  
> **R** — Ответственный (делает), **C** — Консультирует, **I** — Исполняет (участвует), **A** — Утверждает (последнее слово).

##  Экстренные контакты (Кого трясти в первую очередь)

| Ситуация                                         | Контактное лицо                  |
| :----------------------------------------------- | :------------------------------- |
| **Сломался билд, критический баг в прод-версии** | Техлид (срочно в личку / звонок) |
| **Непонятно, как работает игровая механика**     | Гейм-дизайнер / Техлид           |
| **Код упал, не могу запустить Unity**            | Техлид или любой разработчик     |
| **Нужны спрайты / арт для новой фичи**           | Художник                         |
| **Нет звуков на новые ноты**                     | Саунд-дизайнер                   |
| **Срочно нужен апрув на PR (ревью)**             | Техлид                           |
| **Вопрос по задаче / дедлайну**                  | Голова необходимого отдела       |

## Процесс коммуникации

1. **Рабочие вопросы (код, механики, баги):**  
   — Общий чат команды: **[Telegram]**  
   — Для срочных вопросов — личные сообщения ответственному (см. таблицу выше).

2. **Документация и формальные запросы:**  
   — `Change Request` (CR) — через **GitHub Issues** (по шаблону), либо рабочую почту.  
   — `Code Review` — через **Pull Request** в репозитории (по шаблону).  
   — Быстрые правки (мелкие баги, баланс) — почта `ezr.issue@gmail.com`.

3. **Планирование и синхронизация:**  
   — После встречи — заполняется `Meeting Draft` и выкладывается в папку `Logs/Meeting Notes/`.

4. **Конфликтные или спорные ситуации:**  
   — Если решение не может быть принято внутри команды — последнее слово за **Техлидом** или **PM** (в зависимости от типа вопроса).

## Онбординг (для новичков)

Если ты только присоединился к IT команде:

1. **Познакомься с командой** (см. таблицу выше) — добавь всех в контакты.
2. **Прочитай** главный `README.md` и `_Code Style.md`.
3. **Настрой проект** по `Guides/Setup.md`.
4. **Задай вопросы** в общем чате.
