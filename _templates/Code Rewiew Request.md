# Запрос на код-ревью (Code Review Request)

Этот документ описывает, как запросить ревью кода перед мержем в основную ветку (`develop` / `main`).

---

##  Когда подавать запрос

- Ты закончил фичу и хочешь замержить её в `develop`.
- Ты исправил баг и хочешь залить хотфикс в `main`.
- Ты рефакторил существующий код и хочешь убедиться, что не сломал логику.
- Ты добавил новую систему и хочешь получить фидбек по архитектуре.
- Ты изменил структуру или добавил метод в уже существующий скрипт.
- Что-свое (но весомое).

> **Важно:** Ни один код не попадает в `develop` или `main` без прохождения код-ревью.

---

## Шаблон запроса

Скопируй этот шаблон в новый \*.md файл с названием фичи или бага, после кидай его в чат отмечай тех лида/вед разраба, либо брось на общую раб почту:

```markdown
# Code Review Request: [Название фичи / бага]

## Общая информация
 Автор : @username 
 Ветка : `feature/nazvanie` → `develop` 
 Связанные задачи : #ISSUE-123, #CR-456 
 Оценка сложности : Лёгкая / Средняя / Сложная
