# Процесс запроса изменений (Change Request)

Этот документ описывает, как предложить изменение в любой части проекта — код, геймдизайн, контент, архитектура, работа с гитом.

---

## Когда подавать запрос:

- Нужно изменить логику существующей механики.
- Переименовать/переместить папку или скрипт.
- Изменить баланс.
- Добавить новое поле в структуру данных.
- Улучшить производительность в узком месте.
- Сменить используемый пакет/плагин.
- Что-то своё (обязательно указать в категории)

---

## Шаблон запроса

Создай новый \*.md, где звездочка название изменения и закинь его в общий чат, отметь в сообщении тех лида/вед разраба.

```markdown
# Change Request: [Краткое название]

## Общая информация
 Автор : @username 
 Дата : ГГГГ-ММ-ДД 
 Приоритет : Критичный / Высокий / Средний / Низкий 
 Категория : Код / Геймдизайн / Архитектура / Контент / Git / Другое 
 Связанные задачи : #ISSUE-123, #PR-45 

---

## Описание изменения
**Кратко:** [Одно предложение, что нужно изменить.]

**Подробно: **
- [Опиши, что конкретно ты хочешь изменить.]
- [Почему это сейчас работает не так или неудобно?]
- [Как это повлияет на остальные системы?]

---

## Причина изменения (проставь галочки)
- [ ] Баг / Ошибка в текущей реализации
- [ ] Улучшение производительности
- [ ] Упрощение кода / Улучшение читаемости
- [ ] Добавление новой функции
- [ ] Гейм-дизайн / баланс
- [ ] Другое: ___________

---

1. [Шаг 1: например, изменить метод `SpawnNote()` в `SpawnManager.cs`]

**Альтернативные варианты (если есть):**

- [ ] Есть ли риск потери производительности?
